# Context-Aware Next-Word Prediction

A Natural Language Processing project focused on predicting the next word in a sequence based on its preceding context.

The project uses the WikiText-2 dataset and follows an end-to-end language modeling pipeline, including text cleaning, tokenization, vocabulary construction, handling of unknown tokens, context-window generation, model training, validation, and final testing.

## Key Components

- WikiText-2 dataset preprocessing
- Text cleaning and tokenization
- Training-based vocabulary construction
- Unknown token (`<UNK>`) handling
- Context-window generation
- Next-word prediction
- Model training and validation
- Test-set evaluation
